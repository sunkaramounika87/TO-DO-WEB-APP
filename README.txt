# 📝 To-Do Web App

A modern and responsive **To-Do Web Application** developed as **Task 04** of my internship at **SkillCraft Technology**.

The application helps users organize their daily tasks by allowing them to add, edit, complete, delete, and manage tasks with specific dates and times.

---

## 🚀 Features

* ✅ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ☑️ Mark tasks as completed
* 📅 Set a date for tasks
* ⏰ Set a time for tasks
* 🔍 Filter tasks by:

  * All
  * Pending
  * Completed
* 💾 Tasks are stored using **Local Storage**
* 📊 Displays total and pending task counts
* 📱 Fully responsive design
* 🎨 Modern and attractive user interface
* ✨ Smooth hover effects and animations
* 🌈 Gradient and glassmorphism-inspired design

## 🎯 How It Works

1. Enter your task in the **Task** field.
2. Select a **Date** and **Time** if required.
3. Click **Add Task**.
4. The task will appear in the task list.
5. Click the **✓** button to mark a task as completed.
6. Click **✏️** to edit a task.
7. Click **🗑️** to delete a task.
8. Use the filter buttons to view **All, Pending, or Completed** tasks.
9. Tasks remain saved even after refreshing the browser because **Local Storage** is used.
